# Cinemana Pro — Obsidian 04 / Liquid Glass V4

تجربة مستقلة HTML/CSS/JS، لا تعديل على GitHub أو APK. افتح ملف `Cinemana-Liquid-Glass-V4.html` في متصفح حديث؛ لا تحتاج شبكة أو CDN. المشروع المفصول يعمل أيضاً من `index.html` مع الأصول. استخدم `python build.py` لإنتاج HTML موحّد في المجلد الأب. التوافق والأداء على جهاز Android يحتاجان تحققاً مستقلاً.

## جرّب هذه المسارات
1. الرئيسية → الزجاج → منشوري (Prism) → تم؛ مرّر المحتوى خلف الشريط السفلي. قارنه بالمتوازن والخفيف. إن ظهر تشوّه مزعج أو بطء استخدم المتوازن.
2. في مختبر الزجاج حرّك المؤشر فوق العدسة، جرّب الإضاءة وتخصيص اللون والمظهر والتباين والحركة.
3. التحميلات → اختبار → إضافة 480 عنصر اختبار. جرّب تصفية «متوقف»، البحث، السابق/التالي والإيقاف الجماعي. ثم احذف عناصر الاختبار فقط.
4. ابحث عن ناروتو مع التشكيل أو دونه، افتح التفاصيل ثم ارجع، وجرّب البحث السابق والتحميل المتعدد.

## الملفات
- `index.html`: هيكل الواجهة وSVG map مضمن؛ `style.css`: الأنماط والتوكنز؛ `app.js`: الصفحات والطابور والمحاكاة؛ `optics.js`: العدسة الاختبارية.
- `assets/`: قصاصات من صور المالك السابقة؛ `DESIGN.md`: الهوية؛ `CINEMANA_UI_MASTER_AR.md`: سجل البحث والمصادر وقرارات الهندسة والمستقبل.
- `build.py`، `test_ui.py`، `test_v2.py`، `test_v3.py`، `test_v4.py`؛ `test_storage_v4.py` تجربة أصل تخزين حقيقي تعذرت بسبب حظر التنقل؛ `test-results-v4.json` نتيجة الاختبارات الجديدة.
- `hyperframes/`: تركيبة 18 ثانية 1920×1080، لقطات حقيقية من V4، GSAP timeline. تحتاج بيئة Node/npm وGSAP عند التصيير؛ لا يوجد MP4 ولا تحقق CLI في هذه النسخة.

## التحقق المحلي
`python build.py` ثم `node --check app.js` و`node --check optics.js` ثم `python test_ui.py`، `python test_v2.py`، `python test_v3.py`، `python test_v4.py` (يلزم Python مع Playwright وPillow وChromium في `/usr/bin/chromium`).

## الحدود
كل البيانات تجريبية. حفظ الحالة اختبر عبر storage shim فقط؛ محاولة origin حقيقي فشلت بـ ERR_BLOCKED_BY_ADMINISTRATOR. لا خلفية native؛ لا بث أو تنزيل فعلي. لا قياس FPS/RAM/حرارة على POCO. فلتر SVG اختبر بصرياً في Chromium؛ مسار WebGL لم يعمل في بيئة V3/V4، Canvas بديل. لا ضمان تطابق Android WebView. لا تدّعي هذه التجربة الوصول إلى WCAG AA بالكامل دون فحص مستقل.
